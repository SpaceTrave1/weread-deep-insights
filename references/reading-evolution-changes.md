# 阅读观点演化实施记录

研发只使用合成数据和模拟接口，不读取真实笔记或凭证，不调用微信读书或模型 API。语义质量目标需要独立人工评测，不能从工程测试通过推导。

## 阶段一：历史证据

- 原采集丢弃外层 `reviewId`，划线缺少源标识和修改时间；保留接口实际提供的字段，缺失时明确为临时身份。
- 新增标准库 SQLite 历史库：数据集隔离、笔记实体、内容版本、采集观察、覆盖状态及反馈日志。内容编辑不会增加独立笔记数；书名更正不会制造内容版本。
- 创建、修改、观察时间分开；编辑和恢复旧内容不重定年到原创建时间。第一批历史内容的原始版本未知。
- 失败、空数据和本次未取得均不推断删除；冲突源版本和非法采集时间事务回滚。清理只处理指定历史库，导出、报告、备份需另行清理。
- 先写 14 项历史契约测试，确认模块不存在时失败，再实现；增加恢复旧版本测试后，全套 98 项测试通过。原有 83 项测试基线通过。
- 保留旧分析包 1.0 和旧 CLI 行为；历史模块只在新入口使用。Gateway 版本从此前待提交的 1.0.3 更新为 1.0.4。

后续阶段的实际验证结果将在完成后追加。
