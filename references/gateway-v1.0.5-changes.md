将共享 Gateway 版本更新为 `1.0.5`。请求 body 的 `skill_version` 与采集输出的 `skillVersion` 共用此声明。保留参数平铺规范及 `upgrade_info` 立即终止、不重试、不被可选请求容错吞掉的行为。

新增合成回归测试：以模拟空成功响应运行真实请求构建和采集流程，检查全部请求上报版本、笔记目录参数平铺及采集元数据版本一致。测试不读取 `.env`，只使用虚构凭据，不发起任何真实 API 请求。此次仅查询官方公开文档，不重新采集个人数据。

验证结果：采集／基础报告相关 39 项测试通过，全套 162 项合成／模拟测试通过；Python 编译、网页 JavaScript 语法及 Git 差异空白检查通过。
