# v0.2 第一阶段可靠性变更说明

实施日期：2026-10-09。开发分支：`reliability/v0.2-phase1`。所有测试、样例与回归快照均为合成数据；未读取真实 API Key、`.env` 或个人笔记，未调用真实微信读书 API。

| 发现的问题 | 修复方式 | 对应验证 |
| --- | --- | --- |
| 请求失败占位项被 `len()` 计入划线/点评，污染占比及评分 | 错误与正文分离；统一筛选非错误、非空字符串正文；兼容过滤旧 `error` 占位项；保留分页中已经成功获取的有效正文 | 旧占位项、空文本、异常正文、失败/空响应、部分分页回归 |
| 进度和详情失败/空行也被计入有效导出 | 每行记录请求状态，只计成功非空行 | 模拟成功、失败与成功但为空的进度/详情 |
| 抽样或接口失败时 HTML 仍声称全量，跳过和旧数据状态不透明 | 两种报告增加按端点/书籍/年度的覆盖、失败、未请求和未知计数及文本分母；始终限制为本次可见数据 | 抽样、跳过、零本抽样、缺 ID、目录中断、双格式渲染 |
| 分页停滞/达到上限被当作完成，重复页可膨胀统计 | 明确分页中断异常并保留已取得行；检测游标循环；按显式 ID 去重 | 正常游标、停滞、循环、重复书籍/点评 ID |
| 总览失败导致整体报错，或缺失统计被读成零 | 保存顶层状态并继续处理其他可见数据；失败年度不渲染为零；缺失官方指标显示未获取；无效计数字符串不按零处理 | 模拟总览失败与目录中断、无效/不一致官方计数 |
| `upgrade_info` 被重试或局部容错吞掉 | 专用异常立即停止，贯穿可选采集 | 模拟传输和可选笔记升级响应 |
| 空/薄数据仍生成性格、情绪、动机和固定盲区 | 画像/思考线索设点评数量和跨书证据门槛；划线、书名与本人主张区分；盲区仅保留条件触发的可核查风险 | 空数据、仅划线、单书大量点评、同名不同 ID、足量多书点评 |
| 维度存在 35/45/58/62 等无证据底分，茧房把点评比例当风险 | 移除固定底分；缺证分数为 `None`；支持的分数使用明示比例；茧房改为返回数据的集中信号；行动、问题质量与现实敏感度不评分 | 精确比例、部分获取不评分、证据不足不判低风险 |
| 获取、规则和模板挤在单文件，难以独立回归 | 先建立测试，再依次提取共享工具/获取、分析和渲染；入口保留原函数导出与 CLI | 每次提取后运行全套；拆分前后同一合成报告分析 JSON、Markdown、HTML 的 SHA-256 全部一致 |

验证记录：基础 10 项通过；采集与覆盖修复后 16 项通过；证据条件修复后 23 项通过；三步模块拆分分别重跑 23 项通过；最终扩展到 38 项，全部通过（Python 3.12.14 标准库 `unittest`）。测试显式禁止网络与 `.env` 加载，并检查禁止对象没有被调用，防止异常被容错捕获后误判通过。直接脚本和 `python -m scripts.generate_deep_report --help`、Markdown/HTML/both 三种输出均被验证。

复现命令：

```bash
python -m unittest discover -s tests -v
python -m compileall -q scripts tests
git diff --check
```

兼容性与风险：

- 保持标准库依赖、全部原有 CLI 参数及默认值、输出文件名、HTML 模板与 `SKILL.md` 的运行路径。环境变量加载位置因文件仍位于 `scripts/` 而不变。Gateway `skill_version` 仍为 `1.0.3`，它与本次仓库阶段版本独立。
- 评分口径和部分措辞有意改变；内部报告结构增加覆盖和证据字段，缺证分数为 `None`。外部依赖数值型固定分数或逐字匹配原报告的调用方需要适配。入口函数导出仍可导入，但模拟传输和环境加载应替换 `scripts.collection` 内的依赖。
- 旧数据无请求状态时明确显示未知，并保守关闭依赖完整覆盖的评分。分页部分成功的文本仍可贡献局部证据，不可推定全账户分布。
- 数量门槛、关键词和集中等级均是可复现启发式规则，不是经过验证的心理量表。关键词不能处理否定、讽刺或价值认同，分类接口也可能只返回偏好片段。
- 38 项离线测试验证本地逻辑与模拟协议，不声称验证了真实接口当前行为。未进行真实账户集成测试，未推送或部署。
